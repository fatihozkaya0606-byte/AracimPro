# Metal Tarayici test APK
Telefonun Android manyetometre donaniminin olctugu manyetik alan degisimlerini gosterir.
Bu bir altin tespit cihazi degildir; 30 cm-1 m altin algilama menzili saglamaz.
Gercek altin tespiti icin harici VLF / PI bobin ve elektronik gerekir.
Kaynaklar scanner/ altindadir. Uretim degil test surumudur.
