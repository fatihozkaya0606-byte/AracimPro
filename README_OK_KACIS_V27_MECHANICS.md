# Ok Kaçış V27 — 540 aşamalı mekanik genişletmesi

**Test dalı.** V26 mat ahşap tasarımını, V25 şeffaf dokunma yüzeyini ve 9×9 / 540 seviyeyi korur. Google Play üretimine otomatik yüklenmez.

| Seviye | Öğrenilen/uygulanan mekanik |
|---|---|
| 1–10 | Eski anahtar, kilit, engel ve özel güçler |
| 11–15 | ❄️ Buz çözme (önce çözücü oku çıkar) |
| 16–20 | 🚪 Tek yönlü tünel kapısı (önce kapı oku) |
| 21–30 | 🔘 Düğmeli kapı (yeni başlayanlar yanlış dokununca hamle eksilmez) |
| 31–40 | ⛓️ Zincirli oklar |
| 41–50 | 🎨 Renk anahtarı (aynı renkteki ok kilidi açar) |
| 51–60 | ⏳ Süreli kapı (8 saniye açık, 4 saniye kapalı; yeniden açılır) |
| 61–100 | Üç mekanikli karma bulmacalar |
| 101–180 | 🔐 İki anahtarlı kilit ve karma bulmacalar |
| 181–300 | 🔄 Döner yön kapısı ve diğer kilitlerle zincir |
| 301–420 | Usta aşamaları, üçlü karma |
| 421–540 | Dörtlü efsane bulmacalar |

**Solvability:** Anahtar bağımlılıkları yalnızca daha sonra yerleştirilen oklara bağlanır. Orijinal üreticinin ters yerleştirme sırası tam çözüm verir. Süreli kapılar periyodik açılır, kalıcı kapalı kalmaz. Her 540 seviye testte doğrulanır.

**UI:** Mat oyunda küçük simgeler, ipucu ve otomatik hamle yeni kurallara uyar; V25 dokunma kodu ve eski kayıt anahtarı değişmedi. Bu oyun mekanikleri tamamlandığında Android test APK kullanılarak görsel ve dokunmatik doğrulama ayrıca yapılmalıdır.
