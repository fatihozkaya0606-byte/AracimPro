# Piyasa Atlas Premium V0.5 — Android test sürümü

- Android'de animasyonları azalt ayarı aktif olsa bile JS kontrollü kayan fiyat bandı (33 ms güncelleme, görünürken aktif).
- 206px kompakt premium tanıtım kartı: 3.8 saniyede bir otomatik değişen dört sahne.
- Süre ilerlemesini gösteren görsel çubuk ve manuel sahne değiştirme.
- Dolar/gram altın/BIST XU100: uygulama görünürken yaklaşık 10 saniyede bir kaynak kontrolü; fiyatın kaynaktaki zamanı ayrı tutulur, fiyatın yeni olacağı garanti değildir.
- Kripto WebSocket akışı aynı bırakıldı.
- Aylık API kotasını korumak için istek tekrarı engelleme, hata halinde artan bekleme ve ekran kapalıyken duraklatma korunur.
- BIST verisinin halka açık dağıtımına ilişkin lisans gereklilikleri ayrıca doğrulanmalıdır.
- Önceki Piyasa Atlas test sürümleriyle aynı paket imzasıyla v0.5.0 geçişi.
