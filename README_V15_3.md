# Aracım Pro V15.3 — Kesin Varyant + Kota Dostu Teknik Veri

- OtoAPI kesin varyant seçimi ve `carId` saklama
- Seçili carId ile tek istekten teknik detay
- Açılışta tüm kayıtlı araçları otomatik sorgulama kaldırıldı; Free API kotası korunur
- OtoAPI kullanım/kota göstergesi
- Araç Data Merkezi için güvenli Cloudflare Worker şablonu
- V15.2 konum, splash, sabit debug imzası, kullanıcı/yorum altyapısı korunur

Not: OtoAPI kataloğu çok geniştir ancak sağlayıcıda bulunmayan bir varyant için uygulama veri uydurmaz. Gerçek Türkiye piyasa değeri için ayrıca lisanslı değerleme API tokenı gerekir.
