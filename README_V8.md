# Aracım Pro V8 — Seçimli Araç Kataloğu

V8 sürümünde kategori niteliğindeki alanlar serbest metin yerine seçimli hale getirildi.

## Araç ekleme
- Model yılı: seçim
- Marka: seçim
- Model: çevrimdışı Türkiye odaklı katalog + internet varken NHTSA vPIC geniş model kataloğu
- Araç türü / kasa: modelden otomatik öneri + seçim
- Yakıt, motor, şanzıman, çekiş, paket ve renk: seçim
- Model seçildikten sonra gerçek araç fotoğrafı arama devam eder.

Plaka, kilometre, fiyat, tarih ve isteğe bağlı not gibi kullanıcıya özgü bilgiler doğal olarak elle girilir. Beygir/tork gibi varyanta göre değişen teknik sayılar yanlış tahmin edilmemesi için isteğe bağlı ileri bölümde bırakılmıştır.

## Diğer kayıt ekranları
Yakıt istasyonu, kullanım türü, yolculuk amacı, servis türü/işlemi, bakım işlemi, lastik markası/ölçüsü, akü markası/kapasitesi, hasar türü/durumu, değer kaynağı ve sigorta şirketi seçim listelerine çevrildi.
