# Ok Kaçış V26 – Clean Matte Wood UI
V25 (540 bölüm, 9x9, şeffaf tam-tahta dokunma) üzerine **yalnızca CSS** görsel revizyonu.

- Daha sade, ceviz dış çerçeve ve düşük kontrastlı meşe kareler.
- Cam gibi parlak bloklar yerine yumuşak mat kil/plastik görünümü.
- Mat pastel turuncu/mavi/yeşil/mor/sarı/kırmızı bloklar, net beyaz ve koyu konturlu SVG oklar.
- Hedef, hamle, can, süre, etiket, kombo, güç ve alt üç düğmede temiz ortak stil.
- Ana sayfa, seviye kartı, mağaza ve modal yüzeylerde uyumlu renkler.
- Hiçbir dokunma işleyicisi, seviye kuralı, API, reklam, kayıt sistemi veya oyunun 9×9 ölçüsü değiştirilmedi.
- İzole debug APK'dır; Google Play'deki sürümü etkilemez.

Doğrulama: `node --test game-development/*.test.js`, Android debug build ve gerçek telefon görsel/dokunma denemesi.
