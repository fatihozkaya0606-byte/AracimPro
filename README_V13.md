# Aracım Pro V13 5.3.0

- Tüm kayıtlı araçlar için seri teknik veri sorgu kuyruğu.
- Mercedes E/C/S Serisi, BMW seri adları ve bazı katalog adları için API alias eşleştirmesi.
- Araç Rehberi artık VIN istemez; VIN yalnız üretim yeri gibi şasiye özel bilgiler için isteğe bağlıdır.
- Araç rehberi açılınca eksik teknik veriler otomatik sorgulanır ve sonuç geldiğinde ekran yenilenir.
- Chery Tiggo 7 Pro ve Tiggo 8 Pro Türkiye 1.6 T-GDI profilleri yerel teknik veri olarak eklendi.
- Kayıtlı tüm araçları tek tuşla yeniden sorgulama eklendi.
- Teknik veri bulunmayan varyantlarda sahte HP/tork/0-100 üretilmez; veri servisi hatası açıkça gösterilir.
